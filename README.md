## Описание
Телеграм-бот для подбора фильмов и сериалов с поддержкой русского языка. Пользователь может искать конкретное название, пройти интерактивный опрос по жанрам/возрастным ограничениям/настроению или отправить отчёт об ошибке. Источник данных — TMDB API, а ранжирование по настроению выполняется через Google Gemini (опционально).

## Основные возможности
- `/start` с приветствием и быстрым меню.
- Поиск по названию с каруселью результатов и постерами.
- Поиск по предпочтениям: тип контента → возрастной рейтинг → жанры → настроение → период выпуска; выдача учитывает настроение при наличии `GEMINI_API_KEY`.
- Получение списка доступных стриминговых сервисов (провайдеры TMDB для RU).
- Отправка отчёта об ошибке админу (чат задаётся через `REPORTS_CHAT_ID`).

## Стек и зависимости
- Python 3.12+
- [Aiogram 3.22](https://docs.aiogram.dev/)
- aiohttp, asyncio
- python-dotenv + pydantic (конфиг)
- TMDB API
- Google Gemini API (для mood-based ранжирования — необязателен)

## Переменные окружения
Создайте файл `.env` в корне репозитория (`bot/config.py` использует dotenv):

| Переменная          | Обязательна | Назначение |
|---------------------|-------------|------------|
| `BOT_TOKEN`         | да          | Токен Telegram-бота (BotFather) |
| `TMDB_API_KEY`      | да          | API ключ TMDB (https://www.themoviedb.org) |
| `WEBHOOK_BASE_URL`  | да          | Базовый URL для webhook (например, `https://yourdomain.com`) |
| `WEBHOOK_PATH`      | да          | Путь для webhook (например, `/webhook` или `/bot`) |
| `GEMINI_API_KEY`    | нет         | Ключ Google Gemini; если отсутствует — ранжирование по настроению будет пропущено |
| `REPORTS_CHAT_ID`   | нет         | ID чата/канала для отчётов об ошибках (можно оставить 0) |

## Запуск
```bash
python bot/main.py
```
После старта бот запустит webhook-сервер на указанном порту (по умолчанию 8080) и установит webhook по адресу `WEBHOOK_BASE_URL + WEBHOOK_PATH`. Убедитесь, что ваш сервер доступен извне и может принимать POST-запросы от Telegram.

**Примечание**: Для локальной разработки можно использовать polling-режим, но текущая реализация использует webhook.

## Сценарии использования
- **Поиск по названию**: нажмите «Найти по названию» → отправьте часть или полное название → листайте результаты кнопками ◀️ ▶️ → «Завершить поиск» покажет доступные сервисы.
- **Поиск по предпочтениям**: бот задаёт серию вопросов (тип, возраст, жанры, настроение, годы). После подбора можно листать результаты, запросить места просмотра или вернуться в меню.
- **Отчёт об ошибке**: «Сообщить об ошибке» → выберите категорию → опишите проблему; бот пересылает сообщение в `REPORTS_CHAT_ID`.
